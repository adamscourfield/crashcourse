# Student mastery dashboard — 23 October 2026

## Purpose and interface

A persistent My progress navigation item shows completed/eligible lessons for the selected subject. Its dashboard provides a completion ring, completed/remaining/in-progress counts, Discover/Investigate/Practise/Check milestone totals, practice and independent-check accuracy, flagged concepts/skills, topics due for recall, and expandable topic/lesson progress. Lesson links continue at the first unfinished milestone; gap links reopen a lesson for revision; review links open the chosen topic’s existing spaced recall. Planned subjects have no progress dashboard. Science and Maths use the same presentation.

## Metric definitions and scope

Science denominator is eligible lessons across all Science topics for the chosen Trilogy/separate route and Foundation/Higher tier. Completion is derived from the existing four gates, including filtered teaching/check items and widget requirements, on a copy; simply opening progress cannot grant completion, erase progress or schedule recall. Independent checks require all eligible answers and80% correct. Practice first tries use each question’s original recorded answer, preserving a mistake even after correction. Current check accuracy counts recorded answers in latest lesson-check runs, including unfinished runs; unanswered questions are excluded, not counted as wrong. Review/assessment scores are not silently mixed into that metric. Historical retakes are not represented as a lifetime or exam-grade average.

Maths denominator is the built lessons for the selected tier (50Higher/47Foundation at this release), not the entire future Maths specification. Milestones follow existing lessonDone/mastery rules; skill security respects tier-specific practice levels. Recent unassisted accuracy uses retained eligible-level skill logs, up to60 per skill, excluding assisted examples. Latest independent-check accuracy filters to eligible skills/levels. Existing best-check rules and saved progress are unchanged; no historical tier migration or reinterpretation of old best scores is performed.

Science gaps are eligible concepts flagged needsReview. Maths gaps include flagged skills and an eligible-level latest practice mistake; later correct practice clears the latter unless recall is still flagged. Concepts/skills are deduplicated in global totals. Recall topics use the current due/needsReview schedule. Successful recall clears flags through the existing engine. No-attempt accuracy is shown as a dash with an explanation, not0%. Progress is browser/device-local and not a predicted GCSE grade or practical/specialist certification.
