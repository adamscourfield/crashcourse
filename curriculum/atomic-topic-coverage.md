# Atomic structure and periodic table: implemented topic map

Checked against AQA online specifications, 16 October 2026. References below use separate Chemistry 4.x; Trilogy uses 5.x for shared content. The full GCSE is not implemented. Original lesson text and questions are in `science-app/dist/content.js`.

| AQA reference | Implemented lesson | Activity evidence |
|---|---|---|

This is a curriculum alignment inventory, not independent teacher validation or AQA endorsement. Cross-topic equations are introduced here and need further applications in later chemistry topics. Scientific diagrams deliberately simplify scale and apparatus. Required practicals still require the school laboratory activities.
