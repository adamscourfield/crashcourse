## Learning and assessment design

Each lesson:3short explanations,4model views and4feedback-led challenges,3practice and4fresh independent selected-response questions. Original stable question/concept IDs geo.a.final.<slug>.p1–3/c1–4; keys and feedback canonical in content-final.js. Prior concepts: generic enquiry lessons, relevant landscape/city/rural concepts, basic number/coordinates/graphs. Misconceptions diagnosed: water stage equals discharge; qualitative means invalid; one photo proves rate; larger raw total means larger rate; same colour means same spatial value; logarithmic steps add; percentile is percent correct; correlation is causal; ecological footprint is tonnesCO2e. Corrective feedback explains the mechanism and defined units.

## Discover / Investigate / motion decision

Every model distinguishes genuine dated evidence from illustrative diagrams. Field processes show direction/sequence inline with default autoplay+Loop, reduced-motion paused start and pause/step controls. Actual datasets/maps and evidence comparisons stay still; no pretend measurement animation. All14lessons include a required student-input mini-lab in the fourth view: typed quantities or explicit map/representation choices. Plotted bars and best-fit line update from the student's entries; GIS highlights an actual retained polygon using selected code/year. Drafts, first submitted model answer and checked state persist. Editing a correct draft invalidates its gate until checked again; watching never earns this gate. Model lab must pass as well as all4views/tasks for Investigate completion. Command-word draft stored locally, self-reviewed and explicitly unmarked; never claimed to be automatically assessed writing.

Lab feedback targets definitions/working. Independent check does not include the worked model or solutions; neutral fresh stimulus only where needed. First independent answers lock, navigation automatic,4/4 required for>=80%; failed check remediates and permits retake. Existing practice first-attempt/retry and due-concept scheduling retained. Option changes hide but preserve progress, including model drafts. Phone/keyboard controls use labels; no colour-only required evidence. Model numerical bounds prevent nonfinite SVG geometry.

## Subject-specific evidence and limits

Primary source check28Oct2026: Pearson, RGS river techniques, BGS geology viewer, OS cartography, ONS Census maps, DESNZ conversion-factor collection and GlobalFootprintNetwork methodology. Retained authentic image credits and raw geospatial/attribute files stay intact. Source snapshots/hashes in final-selected.json. Carbon example factors are deliberately invented, not2026DESNZ factors. Ecological toy divides demand by stated yield then equivalence factor; full real accounts require full boundaries/data/yield factors and are not reproduced.
