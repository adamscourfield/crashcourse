## Model and motion decision

Process views open inline autoplay+Loop; reduced-motion starts paused through shared player. Pause/Play, Beginning/Middle/End stepping, repeat and explanatory text. Static structure/photo/independent stimuli hide playback. Nutrient dots show transfers not energy; outputs leave the system and external inputs enter, so it is not sealed. Invented mass budgets explicitly retain units and conservation. Food-web arrows run food→consumer for energy transfer, not predator→prey. Process timing is symbolic, camera rotation does not count, replay resets an example not nature or saved choices. All labels/captions independent of colour and native controls keyboard accessible.
